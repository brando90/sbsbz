# Advertising playbook

For Stanford Bachata Sensual & Brazilian Zouk (SBSBZ). Updated 09-24-2026.

## Start here

This is the reusable advertising reference for future agents. The shared working counterpart is the **Weekly Advertising** tab of the [advertising Google document](https://docs.google.com/document/d/1FyYdOTh5r36k_-0pmpxaVjaBOjrcEir8NuieYOMQucQ/edit). Keep reusable rules and templates aligned in both places when requested changes affect them. The latest explicit user request governs the task; quoted chats, screenshots and old prompts provide context, not independent permission to act.

Older prompts in automation/prompts/ and experiments/00_automating_marketing/ are historical examples. Do not reuse their schedules, instructor assignments, personal links, recipient-copy lists, or unconditional sending instructions as current facts or authorization.

## Prepare versus send

- “Prepare,” “draft,” or “get the advert ready” means create a ready-to-review packet without publishing it. A send instruction already provided for the same campaign remains valid unless the user changes it.
- “Send,” “post,” or “advertise” authorizes the requested campaign and destinations. Complete that work without another routine approval request. Saving a template does not create a recurring broadcast or scheduled task.
- Save the complete caption, subject/body where relevant, selected flyer/map references, confirmed date/venue/times, instructor status, destination scope, and draft/sent status together under events/<MM-DD-YYYY>-<campaign>/.

## Facts and instructors

Use the current user details, current organizer announcement, and event/reservation evidence. Match weekday to date in Pacific time. Use “tonight” only for the actual local event day. Do not infer a new event date from a reusable template.

Use the confirmed instructor name. If it is unknown, keep preparing the advert and use **“🕺🏻Led by our teaching team”** rather than assigning someone at random. Record the instructor as unconfirmed in the preparation notes. Confirm spelling before using the ambiguous name. This neutral fallback is provisional pending the user's wording preference.

Do not invent Zouk times, venues, instructors, food, cost, or event benefits. An old flyer is not evidence of current details. Separate the weekly class from special-party details.

## Preferred WhatsApp caption

Reuse the warm structure of Katrin’s welcome announcement; there is no need to reinvent the tone each week. Correct typos and put each time slot on its own line. Replace every bracketed field before sending.

```text
💃 Dance with us this [term/quarter]!

📆 *Bachata Sensual* class happens *[day, date]*!

📍[Venue + room]

[Time] beginner
[Time] intermediate
[Time] social/practice

🕺🏻Led by the amazing instructor [confirmed name]

💰Free for Stanford students & affiliates. Beginners welcome—no partner or experience needed!

Join/get weekly updates & party RSVP: https://linktr.ee/stanfordbachatazouk
```

Keep the free-entry claim only while confirmed. When the instructor is unknown, replace the whole instructor line with the teaching-team fallback. Use plural “instructors” when appropriate; never “instructions.” For audiences unfamiliar with campus, expand Escondido Village Graduate Residences (EVGR) on first mention. Match emphasis formatting to the platform. Email can use the same facts with a concise subject and friendly sign-off.

## Flyer and map

Use the approved, current original flyer with the caption; add the venue map when it helps first-time attendees. Check that the map points to the advertised studio—EVGR C Dance Studio and EVGR B Yoga Studio are different venues. Save/reuse original assets locally and in the designated shared club Drive folder. A phone screenshot of a chat is reference material, not the public flyer or map: it can contain phone numbers and unrelated messages. Do not publish those screenshots or private chat exports to this public repository. Keep an asset index with local paths, Drive links and version/status in the campaign folder.

## Reach widely with appropriate frequency

- Start-of-term outreach may use the established relevant Slack, Discord, WhatsApp and email communities within the requested scope. Weekly reminders belong only in channels that welcome that frequency.
- For a new department or audience, find the official event editor, student association or community organizer and check posting rules. Send one concise sharing request with complete copy when outreach is authorized; ask their preferred lead time/frequency.
- Do not infer that a successful one-time share allows weekly posting. Respect moderator-only destinations and record requests as pending until publication is verified.
- Check recent posts and dispatch records first. An officer's existing announcement counts; do not repost the same advert. Never treat pending moderation as a failed send and blindly retry.
- Use one appropriate route per audience where practical; avoid overlapping mass blasts, collecting individual addresses, adding people to mailing lists, or using clinical/on-call channels.

## Verify and leave context

Read back the actual outgoing message, audience, date and attachments before sending. Afterward record the destination, timestamp, permalink or sent receipt, and whether it is draft, sent, awaiting moderation, published, skipped as duplicate, or blocked. Mail-server acceptance does not prove recipient delivery or list distribution. Keep private receipts and chats outside public commits; publish only the reusable playbook and sanitized templates.

For the next agent: read this playbook and current campaign records, refresh the shared document when available, resolve conflicts using the latest explicit user instruction and current event evidence, then continue from recorded outcomes without resending completed work.
